# Sheetmusic Creator

A music notation editor for choir, orchestra, band and solo.

## Download

Get the newest version under **[Releases](../../releases/latest)**:

- **Mac** (Intel and Apple chip, macOS 11 or newer): download the `.dmg` file, open it and drag *Sheetmusic Creator* into the *Applications* folder.
- **Windows**: download the `-setup.exe` file and run it.

Installed apps look for new versions on their own and offer to install them.

# Sheetmusic Creator (Deutsch)

Ein Notensatzprogramm für Chor, Orchester, Band und Solo.

## Herunterladen

Die neueste Version gibt es unter **[Releases](../../releases/latest)**:

- **Mac** (Intel und Apple-Chip, ab macOS 11): die `.dmg`-Datei laden, öffnen und *Sheetmusic Creator* in den Ordner *Programme* ziehen.
- **Windows**: die Datei `-setup.exe` laden und ausführen.

Installierte Programme suchen selbst nach neuen Versionen und bieten an, sie zu installieren.
